# Report style

Taken from the pstack `unslop` skill. Apply it to the report, to the text you add to a document
and to an issue text.

- State the fact. Give the mechanism or the number, not an impression.
- One idea in each sentence. Active voice; name the actor.
- One name for each thing. Repeat it.
- Use the plain word: "use", not "utilize" or "leverage".
- No filler: "in order to" becomes "to"; delete "it is important to note that".
- At most one hedge: "may".
- No "not just X, but Y". No list of three for rhythm. No "from X to Y" without a real scale.
- No vague source ("experts believe"): name the source or delete the sentence.
- No trailing "-ing" phrase that adds no fact ("ensuring…", "highlighting…").
- No metaphor, aphorism or personified code where a literal phrase exists.
- No dash as a connector. Use a full stop or a comma. A colon goes before a list or an example.
- Sentence-case headings, straight quotes, no decorative emoji, no bold on each name.
- No praise, no chat phrases, no general conclusion. End with the specific open work.
